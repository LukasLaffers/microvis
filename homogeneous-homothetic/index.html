Homogeneous and Homothetic

How to read this

The isoquants are drawn at equal output steps, ; along each ray only the scale changes. Every homogeneous function is homothetic, but not the other way round.

  • Homogeneous: the isoquants are radial blow-ups, with parallel tangents along each ray. Move : the spacing is even for , bunches up for , spreads out for .
  • Homothetic: the same shapes and parallel tangents, but any increasing labels them, so the spacing can change as you move out.
  • Neither: the tangents along a ray turn.
