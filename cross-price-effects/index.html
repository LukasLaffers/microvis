Input 2 gets dearer. Does the firm use more or less of input 1?

How to read this

When rises, the firm first substitutes towards input 1 at the old output (A → B), then produces less and uses less of both inputs (B → C). The first effect raises the demand for input 1, the second lowers it; which one wins depends on how easily the inputs substitute.
