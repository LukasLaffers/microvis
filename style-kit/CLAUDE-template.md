# Conventions (from the Microvis style kit)

Interactive pages published with GitHub Pages. Style guide: see the Microvis style kit README (principles, tokens, components, writing).

## Layout

```
index.html              start page: one tile per page, by section; generated by tools/build-site.cjs, do not edit by hand
shared/style.css        the whole look (colours, type, panels, controls, tiles, layout)
shared/ui.js            helpers every page uses (controls, KaTeX, plot styling, error banner, Safari fixes)
shared/vendor/          Plotly 2.35.2 and KaTeX 0.16.9 with their licenses
tools/catalog.cjs       site title and the pages in reading order, with a one-sentence description each
tools/glyphs.cjs        the 64 x 64 drawing on each tile
tools/build-site.cjs    writes index.html and the header link and previous/next links of every page
<page-name>/            one folder per page, kebab-case: index.html, app.js (and model.js + test-model.cjs for math)
```

## Rules

- Plain HTML, CSS and JavaScript. No framework, no bundler, no npm install, no CDN. Pages work offline and as local files.
- Minimal design: Helvetica/Arial, square corners, hairlines, no shadows, no coloured stripes, no gradients. Black and white plus one blue (`--brand`) for what can be clicked or moved; subject colours only inside figures.
- Text is short and lets the figure speak: a one-sentence tile description; "How to read this" is the idea in two or three sentences, then a short list of things to try. Engaging but academic, precise, never verbose. Name buttons as labelled, in bold; never "below" / "on the right".
- Every page: works on a phone (controls above the figure), has "How to read this", labels its axes, shows the key numbers live, and shows errors in the status banner.
- Add each new page to `tools/catalog.cjs` and its drawing to `tools/glyphs.cjs`, then run `node tools/build-site.cjs`.
- Keep math in `model.js` (UMD) and test it in Node against independent calculations.
- Our own CSS and JS are linked with a version tag (`?v=N`). Raise it in all pages whenever a shared file changes.
- `.nojekyll` stays in the root.
- No contact details on the pages.
- Before publishing: every page loads without console errors; no horizontal scroll at 375px; no unneeded scrollbars at 1440/1280/1024/768px; screenshots checked in light and dark, desktop and phone.
